# Hello, World!

É comum começar o estudo de uma linguagem de programação com um programa que exibe a mensagem "Hello, World!".

## Escrevendo o programa

```javascript
console.log("Hello, World!");
```

## Entendendo o comando

- `console` dá acesso ao console de saída.
- `log()` exibe uma informação nesse console.
- O texto entre aspas é a mensagem que queremos mostrar.

## Prática

1. Abra o console do navegador.
2. Digite o programa.
3. Pressione Enter.
4. Troque a mensagem por seu próprio texto.

## Desafio

Exiba duas mensagens diferentes utilizando dois comandos `console.log()`.

## Resumo

Você escreveu seu primeiro comando JavaScript e utilizou o console para visualizar o resultado.
