# Blocos de código com chaves

Em JavaScript, as chaves `{}` delimitam blocos de instruções em estruturas como condicionais, funções e laços de repetição.

A indentação não costuma determinar o funcionamento do bloco, mas ajuda a manter o código organizado e legível.

## Exemplo

```javascript
if (true) {
    console.log("Dentro do bloco");
}

console.log("Fora do bloco");
```

A primeira mensagem é executada dentro do bloco do `if`. A segunda instrução está fora dele.

## Boas práticas

- Utilize indentação consistente.
- Mantenha as instruções organizadas.
- Confira se cada chave de abertura possui sua correspondente chave de fechamento.

## Resumo

As chaves delimitam blocos de instruções e ajudam a organizar a estrutura do programa.
