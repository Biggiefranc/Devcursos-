# Ambiente de Desenvolvimento

Para começar a estudar JavaScript, você pode utilizar o próprio navegador, sem instalar ferramentas adicionais.

## Utilizando o console

1. Abra o navegador.
2. Pressione F12 ou abra as ferramentas de desenvolvedor.
3. Acesse a aba Console.
4. Digite um comando JavaScript e pressione Enter.

## Primeiro teste

```javascript
console.log("Meu primeiro teste");
```

O texto será exibido no console.

## Outras ferramentas

Editores como o Visual Studio Code facilitam a escrita e a organização de programas maiores.

## Resumo

O console do navegador é uma maneira simples de experimentar os primeiros comandos JavaScript.
