# O que é JavaScript?

JavaScript é uma linguagem de programação de alto nível, utilizada principalmente para criar páginas web interativas. Também pode ser usada no servidor e em outras aplicações.

## Por que aprender JavaScript?

- É muito utilizada no desenvolvimento web.
- Possui uma grande comunidade e muitos materiais de estudo.
- Permite desenvolver funcionalidades interativas no navegador.
- Pode ser utilizada tanto no frontend quanto no backend.

## Exemplo

```javascript
console.log("Olá, mundo!");
```

Esse comando exibe a mensagem no console.

## Resumo

JavaScript é uma linguagem versátil que permite adicionar comportamento e interatividade às aplicações.
