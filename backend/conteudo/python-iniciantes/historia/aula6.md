# Aula 6 - Python 2 e Python 3

Como vimos na aula anterior, o Python passou por diversas versões ao longo de sua história. Entre elas, duas gerações tiveram uma importância especialmente grande: **Python 2** e **Python 3**.
Compreender a diferença entre elas é importante principalmente porque ainda é possível encontrar materiais antigos na internet que utilizam Python 2.

## Python 2

O **Python 2** foi uma geração muito importante para o crescimento da linguagem. Seu lançamento ocorreu em 2000, e durante vários anos ele foi utilizado em uma grande quantidade de projetos.
Porém, o Python 2 pertence a uma geração encerrada da linguagem. Ele não deve ser utilizado como referência para quem está começando a aprender Python atualmente.
Isso não significa que o Python 2 tenha deixado de ser importante para a história da linguagem. Pelo contrário: conhecer sua existência ajuda a compreender muitos projetos e materiais antigos que ainda podem ser encontrados.

## Python 3

O **Python 3** foi lançado em 2008 e representa a base do desenvolvimento moderno da linguagem. Ele introduziu mudanças importantes em relação ao Python 2, tornando vários aspectos da linguagem mais consistentes.
Para quem está começando a aprender Python atualmente, **Python 3 deve ser a referência principal**.
É essa geração que utilizaremos ao longo deste curso.

## Por que existem diferenças?

A criação do Python 3 não foi simplesmente o lançamento de uma versão com alguns recursos novos.
Algumas regras e comportamentos da linguagem foram modificados. Como consequência, determinados programas escritos para Python 2 não funcionam da mesma maneira quando executados em Python 3.
Isso significa que atualizar um projeto de Python 2 para Python 3 pode exigir alterações no código.
O problema não estava limitado ao programa em si. Bibliotecas e outras ferramentas também precisaram ser atualizadas para acompanhar a nova geração da linguagem.

## Um exemplo simples

Uma das diferenças que um estudante pode encontrar ao consultar materiais antigos está na forma de algumas instruções da linguagem.
Por exemplo, em Python 2, era comum encontrar:

```
print "Olá, mundo!"
Enquanto em Python 3 utilizamos:
print("Olá, mundo!")
```

No Python 3, `print()` é uma função.
Por isso, ao encontrar um código antigo na internet, não devemos simplesmente assumir que ele funcionará exatamente da mesma maneira na versão atual.
Esse é apenas um exemplo simples. Existem outras diferenças entre as duas gerações que podem afetar o funcionamento de programas.

## Como lidar com materiais antigos?

Imagine que você está estudando Python e encontra um tutorial publicado há muitos anos.
O material pode ser excelente, mas ainda assim utilizar Python 2.
Por isso, antes de copiar um código encontrado na internet, é importante verificar **qual versão do Python está sendo utilizada pelo material**.
Alguns sinais podem ajudar:

```
Material antigo
      ↓
Verificar a versão utilizada
      ↓
Python 2?
      ↓
Cuidado com diferenças de sintaxe e comportamento
      ↓
Adaptar ou procurar uma referência atualizada
```

Não significa que todo material antigo seja inútil. Muitos conceitos de programação continuam sendo válidos independentemente da versão.
O problema aparece quando tentamos executar diretamente um código desenvolvido para Python 2 em um ambiente Python 3 sem verificar as diferenças existentes.

## Qual versão devemos aprender?

Para este curso, a resposta é simples:

> **Python 3.**

O Python 2 possui importância histórica e ainda pode aparecer em projetos ou materiais antigos, mas o aprendizado atual deve ter como referência o Python 3.
Ao longo das próximas aulas, portanto, todos os exemplos apresentados no DevCursos+ deverão considerar **Python 3**.
Isso também evita uma situação bastante comum para iniciantes: acompanhar um tutorial antigo, copiar o código apresentado e encontrar erros sem entender por que eles estão acontecendo.
