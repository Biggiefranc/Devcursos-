# Aula 1 — O que é programação?

## Objetivo

Antes de começar a escrever código em Python, é importante entender uma coisa básica: **o que significa programar?**
Nesta aula, vamos entender o que é programação, por que ela existe e qual é o papel das linguagens de programação nesse processo.

---


## O que é programação?

Programar é, de forma simples, **ensinar um computador a realizar uma tarefa por meio de instruções**.
Quando fazemos uma atividade no computador, normalmente existe uma sequência de ações acontecendo por trás dela. Um programa é responsável por definir essas ações e determinar como o computador deve reagir a diferentes situações.
Imagine, por exemplo, uma receita de bolo.
A receita apresenta uma sequência:

1. separar os ingredientes;
2. misturar os ingredientes;
3. colocar a massa em uma forma;
4. levar ao forno;
5. esperar o tempo necessário;
6. retirar o bolo.

Para uma pessoa, algumas coisas podem ser óbvias. Para um computador, não.
O computador precisa receber instruções de maneira suficientemente clara para conseguir executá-las.
Programar é justamente transformar uma ideia ou um problema em uma **sequência de instruções que o computador consiga executar**.

---

## Programar é resolver problemas

Programação não consiste apenas em escrever códigos.
Antes de escrever uma linha sequer, precisamos pensar:

> **Qual problema eu quero resolver?**

Depois disso, precisamos descobrir uma maneira de resolver esse problema e transformar essa solução em instruções.
Por exemplo, imagine que queremos criar um programa que calcule a média de duas notas.
Antes do código, podemos pensar:

1. receber a primeira nota;
2. receber a segunda nota;
3. somar as duas;
4. dividir o resultado por 2;
5. mostrar a média.

Essa sequência já é uma espécie de **plano para o programa**.
Depois podemos transformar esse plano em código.

---

## E onde entram as linguagens de programação?

Nós, seres humanos, utilizamos linguagens para nos comunicar.
Um computador, por outro lado, precisa receber instruções em uma forma que possa ser processada pela máquina.
As **linguagens de programação** são utilizadas para escrever essas instruções de maneira estruturada.
Existem várias linguagens, cada uma com suas características e aplicações.
Alguns exemplos são:
Python
Java
JavaScript
C
C++
C#
Go
Rust

Isso não significa que uma linguagem seja simplesmente "melhor" que outra.
Cada linguagem possui características próprias e pode ser mais adequada para determinados tipos de projeto.

---

## E onde entra o Python?

É justamente isso que começaremos a descobrir na próxima aula.
Python é uma linguagem de programação que permite escrever instruções para que o computador execute diferentes tarefas.
Mas antes de começarmos a escrever código em Python, precisamos conhecer melhor a linguagem e entender **por que ela se tornou tão utilizada**.

---

## Pense sobre isso

Imagine que você precise ensinar alguém a fazer uma tarefa que você realiza todos os dias.
Você provavelmente teria que explicar:

- o que fazer primeiro;
- o que fazer depois;
- quais decisões precisam ser tomadas;
- o que fazer quando algo der errado;
- e quando a tarefa pode ser considerada concluída.

Um programa funciona de maneira semelhante.
A diferença é que, em vez de ensinar outra pessoa, estamos descrevendo as instruções que deverão ser executadas pelo computador.

---

## Pratique

Imagine que você precisa criar um programa que diga se uma pessoa foi aprovada em uma disciplina.
Antes de pensar em código, escreva **quais passos o programa deveria seguir**.
Uma possível estrutura seria:
1\. Receber a nota do aluno.
2\. Verificar a nota.
3\. Decidir se o aluno foi aprovado ou não.
4\. Mostrar o resultado.

Não se preocupe em escrever Python ainda.
O objetivo deste exercício é começar a desenvolver o raciocínio necessário para transformar um problema em uma sequência de instruções.
