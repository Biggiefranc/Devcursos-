# Aula 4 - Origem do nome Python

Depois de conhecer a história do desenvolvimento do Python, podemos responder a uma curiosidade bastante comum: **de onde veio o nome "Python"?**
Apesar de a palavra *Python* ser conhecida atualmente por também representar uma cobra, o nome da linguagem **não foi escolhido por causa do animal**.

## Monty Python

Quando Guido van Rossum estava desenvolvendo a linguagem, ele procurava um nome que fosse curto, diferente e que transmitisse uma identidade mais descontraída.
A escolha veio de uma referência ao grupo britânico de comédia **Monty Python**, especialmente ao programa *Monty Python's Flying Circus*.
Assim, o nome Python surgiu como uma referência cultural e não como uma descrição daquilo que a linguagem fazia.
Essa escolha também combina com a intenção de Guido de criar uma linguagem que fosse agradável de utilizar. O nome ajudou a transmitir uma identidade menos formal e mais descontraída para o projeto.

## E a cobra?

A associação entre Python e as cobras veio posteriormente.
Atualmente, é muito comum encontrar imagens de serpentes, principalmente duas cobras enroladas, relacionadas à linguagem. Elas aparecem em logotipos, materiais didáticos, sites e outros elementos do ecossistema.
Porém, **a cobra não é a origem do nome**. A associação visual foi se consolidando posteriormente e acabou se tornando uma parte bastante reconhecida da identidade do Python.
Isso explica uma situação curiosa: quando alguém vê o nome Python pela primeira vez, pode imaginar que a linguagem recebeu esse nome por causa do animal. Na realidade, a referência original era à comédia britânica.

## Uma escolha diferente

A história do nome Python também mostra que o nome de uma tecnologia não precisa necessariamente explicar sua função.
Nomes podem surgir de diferentes motivos: referências culturais, preferências pessoais, características do projeto ou simplesmente uma escolha que o criador considere marcante.
No caso do Python, uma referência a um grupo de comédia acabou se tornando o nome de uma das linguagens de programação mais conhecidas atualmente.

---

## Curiosidade

O próprio Guido van Rossum já explicou que o nome veio do programa **Monty Python's Flying Circus**. A intenção não era fazer referência às cobras.
Por isso, embora a identidade visual atual do Python esteja fortemente associada às serpentes, a origem histórica do nome está na comédia britânica.
