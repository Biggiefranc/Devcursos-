# Aula 3 - História e origem do Python

A história do Python começa no final da década de 1980, quando o programador **Guido van Rossum** trabalhava no CWI (Centrum Wiskunde & Informatica), na Holanda. Durante o período de Natal de 1989, Guido começou a desenvolver uma nova linguagem como um projeto pessoal. A ideia era criar uma linguagem que fosse agradável de programar, suficientemente poderosa para tarefas reais e, ao mesmo tempo, mais simples de utilizar do que algumas alternativas disponíveis naquele período.
O desenvolvimento do Python também foi influenciado pela experiência de Guido com outras linguagens, especialmente a **ABC**, que havia sido desenvolvida no próprio CWI. A experiência com a ABC ajudou Guido a pensar em características que gostaria de manter ou melhorar em uma nova linguagem. A documentação oficial do Python confirma que a linguagem surgiu como sucessora da ABC.
O que começou como um projeto pessoal acabou se transformando em um projeto público. A **primeira versão pública do Python, a 0.9.0, foi disponibilizada em 1991**. A partir daí, outras pessoas começaram a utilizar a linguagem, contribuir com o projeto e participar de seu desenvolvimento.
Esse crescimento foi importante para a história do Python. Uma linguagem de programação não depende apenas de sua sintaxe ou de suas características técnicas para se tornar relevante. Comunidade, documentação, bibliotecas, ferramentas e continuidade no desenvolvimento também são fatores importantes para que uma tecnologia consiga crescer e permanecer útil ao longo dos anos.

## Guido van Rossum

Guido van Rossum é o principal criador e autor do Python. Ele continuou envolvido com o desenvolvimento da linguagem durante sua evolução, enquanto outras pessoas também passaram a contribuir para o projeto.
Em um relato sobre a origem do Python, Guido explica que procurava um projeto para desenvolver durante o período em que seu escritório estaria fechado no Natal de 1989. Ele decidiu criar um interpretador para uma nova linguagem, inspirada em parte pela experiência que havia adquirido trabalhando com a ABC.
A ideia inicial, portanto, não era criar uma das linguagens de programação mais conhecidas do mundo. Python começou de maneira muito mais simples: como um projeto que Guido queria desenvolver durante seu tempo livre.

## Linha do tempo

| **Ano**  | **Marco**                                                 |
| -------- | --------------------------------------------------------- |
| **1989** | Início do desenvolvimento do Python como projeto pessoal. |
| **1991** | Primeira versão pública, Python 0.9.0.                    |
| **2000** | Lançamento do Python 2.0.                                 |
| **2008** | Lançamento do Python 3.0.                                 |


Essa linha do tempo também aparece na apostila original do módulo.
O lançamento do Python 2.0, em 2000, representou uma etapa importante no desenvolvimento da linguagem. Anos depois, em 2008, surgiu o Python 3.0, trazendo mudanças importantes para tornar diversos aspectos da linguagem mais consistentes.
A chegada do Python 3 também trouxe um problema importante: **compatibilidade**. Parte do código escrito para Python 2 não funcionava da mesma maneira no Python 3. Por isso, a transição entre as duas gerações levou bastante tempo e exigiu adaptações de projetos e bibliotecas.
Esse processo mostra que linguagens de programação não são tecnologias completamente estáticas. Elas continuam evoluindo, recebendo novos recursos, correções e mudanças ao longo do tempo.

## O crescimento da comunidade

Um dos aspectos mais importantes da história do Python foi o crescimento de sua comunidade.
Depois da primeira versão pública, desenvolvedores começaram a utilizar a linguagem, encontrar problemas, sugerir melhorias e contribuir com código. Com o passar dos anos, esse processo ajudou a formar um ecossistema composto não apenas pela linguagem, mas também por bibliotecas, ferramentas, documentação e projetos desenvolvidos por diferentes pessoas e organizações.
O próprio Guido destaca que o sucesso do Python foi resultado não apenas de seu trabalho, mas também das contribuições de muitos dos primeiros usuários e desenvolvedores que ajudaram a linguagem a evoluir.
É justamente essa combinação entre linguagem e comunidade que ajudou o Python a sair de seu contexto inicial de pesquisa e se tornar uma tecnologia utilizada em diferentes áreas.

## Uma linguagem que começou como projeto pessoal

Talvez uma das partes mais interessantes da história do Python seja justamente sua origem.
Python não começou como um grande projeto empresarial ou como uma tecnologia criada para dominar o mercado. Seu desenvolvimento começou como um **projeto pessoal de Guido van Rossum durante o Natal de 1989**.
A partir de uma ideia relativamente pequena, a linguagem passou a receber contribuições de uma comunidade cada vez maior e acabou formando um ecossistema utilizado em diversas áreas da computação.
Essa trajetória ajuda a entender que tecnologias importantes nem sempre começam grandes. Muitas vezes, elas começam com uma ideia, um problema que alguém deseja resolver e a disposição para desenvolvê-la.
