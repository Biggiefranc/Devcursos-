# Aula 2 - O que é Python?

Python é uma linguagem de programação de alto nível, interpretada e de propósito geral. Foi desenvolvida com o objetivo de oferecer uma linguagem relativamente simples de escrever e ler, permitindo que o programador se concentre mais na solução dos problemas e menos em detalhes de baixo nível do computador.
Por sua simplicidade e versatilidade, Python pode ser utilizado em diversas áreas da computação, como desenvolvimento de aplicações, automação de tarefas, análise de dados, inteligência artificial, desenvolvimento web e computação científica.
Uma das características que mais chama atenção em Python é a sua sintaxe. Veja um exemplo simples:

```python
print("Olá, mundo!")
```


Mesmo para quem está tendo o primeiro contato com programação, é possível perceber que a instrução é relativamente fácil de interpretar. Nesse caso, a função `print()` é utilizada para exibir uma mensagem.

## Primeiro exemplo

Um programa simples pode receber informações do usuário e utilizá-las posteriormente:

```python
nome = input("Qual é o seu nome? ")
print("Olá,", nome)
```

Nesse exemplo, `input()` permite que o programa receba uma informação digitada pelo usuário. Essa informação é armazenada na variável `nome` e, posteriormente, utilizada pelo `print()` para exibir uma mensagem.
Ainda não é necessário compreender detalhadamente cada elemento desse código. Variáveis, funções e entrada de dados serão estudadas com mais profundidade posteriormente.
O importante neste momento é perceber que Python permite representar instruções de maneira relativamente direta.

## Onde Python pode ser utilizado?

Por ser uma linguagem de propósito geral, Python não está limitado a uma única área. Entre suas principais aplicações estão:


| **Área**                   | **Exemplos de utilização**                  |
|----------------------------|---------------------------------------------|
| Desenvolvimento web        | Criação de sites e sistemas                 |
| Automação                  | Automatização de tarefas repetitivas        |
| Ciência de dados           | Análise e processamento de dados            |
| Inteligência artificial    | Aprendizado de máquina e modelos de IA      |
| Computação científica      | Cálculos e pesquisas científicas            |
| Desenvolvimento de scripts | Criação de pequenos programas e ferramentas |


Essa variedade de aplicações contribuiu para a popularização da linguagem e para o crescimento de seu ecossistema de bibliotecas e ferramentas.

## Por que Python é utilizado por iniciantes?

A sintaxe relativamente simples de Python faz com que a linguagem seja bastante utilizada no ensino de programação.
Entretanto, uma sintaxe simples não significa que aprender programação seja simplesmente decorar comandos. O desenvolvimento de programas exige raciocínio lógico, compreensão dos problemas e prática.
Python pode ser utilizado como uma ferramenta para aprender esses conceitos, que posteriormente também serão úteis no estudo de outras linguagens.

### Exemplo

Considere o seguinte problema:

> Criar um programa que receba duas notas e calcule a média de um aluno.

Antes mesmo de escrever o código, podemos dividir o problema em etapas:
1\. Receber a primeira nota.
2\. Receber a segunda nota.
3\. Somar as duas notas.
4\. Dividir o resultado por 2.
5\. Mostrar a média.
Essa sequência representa uma forma simples de organizar a solução antes de transformá-la em código.
