# O repositório explica como começar

Ao criar um repositório no GitHub, escolha um nome, uma descrição e a visibilidade adequada. Um repositório público pode ser visto por qualquer pessoa; privado limita o acesso às pessoas autorizadas. Não publique dados pessoais ou segredos.

Se o projeto já existe localmente, inicie no GitHub sem arquivos iniciais e conecte os históricos conforme a aula anterior. Se você ainda vai começar, pode criar o README no GitHub e clonar o repositório para trabalhar localmente. São dois pontos de partida diferentes; escolha um para evitar históricos independentes.

Um README na raiz é a apresentação do projeto. Inclua, conforme fizer sentido: o que ele faz, como instalar ou executar, como testar e como pedir ajuda. Não prometa recursos que ainda não existem. Uma licença comunica permissões para reutilizar o código; escolha uma apenas quando souber o que deseja permitir e consulte a documentação oficial.

### Prática

Escreva um README com título, objetivo, pré-requisitos e passos de execução. Peça a outra pessoa para seguir as instruções sem explicação oral. Anote onde ela travou e melhore o texto.
