# Uma Pull Request propõe uma integração

Uma pull request (PR) propõe integrar mudanças de uma branch em outra. Ela permite comparar arquivos, discutir decisões, revisar commits e acompanhar verificações antes do merge.

Ao abrir uma PR, confira:

- **base:** branch que receberá as mudanças;
- **compare:** branch que contém a proposta;
- **título:** qual mudança está sendo proposta;
- **descrição:** por que ela é necessária, o que mudou e como foi verificada.

Uma PR deve ter um escopo que outras pessoas consigam revisar. Se a mudança depender de outra, explique isso. Vincule a issue relacionada quando existir, usando a referência apropriada ou palavras-chave de fechamento documentadas pelo GitHub.

Depois de abrir a PR, novas mudanças na mesma branch aparecem na comparação. A conversa não substitui os commits: registre a correção na branch e explique como respondeu aos comentários.

### Prática

Publique uma branch de documentação e abra uma PR contra `main`. Escreva uma descrição com objetivo, resumo e uma forma de verificar. Antes de criar, confira visualmente a lista de arquivos e o diff para garantir que a comparação contém apenas a tarefa.
