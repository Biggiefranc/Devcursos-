# Faça uma pergunta que tenha resposta lógica

Comparações verificam uma relação entre valores. O resultado é um booleano: `True` ou `False`.

```python
idade = 17
print(idade >= 18)       # False
print(idade == 17)       # True
print(idade != 16)       # True
```

Os operadores mais usados são `==` igual, `!=` diferente, `<` menor, `>` maior, `<=` menor ou igual e `>=` maior ou igual. Repare na diferença: `=` guarda um valor; `==` compara valores.

Você pode comparar resultados de cálculos, textos e números. Combine o resultado com uma decisão na próxima aula.

## Pratique antes de executar

Preveja o resultado de `5 < 3`, `5 <= 5` e `"Python" == "python"`. Depois execute. Letras maiúsculas e minúsculas são diferentes em uma comparação de texto.
