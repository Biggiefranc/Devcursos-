🚀 Funcionalidades

- Cadastro de estudantes: matrícula na plataforma com autenticação pelo Firebase.
- Login: acesso à conta utilizando autenticação Firebase.
- Recuperação de senha: envio de e-mail para redefinição de senha.
- Login com Google: autenticação utilizando uma conta Google.
- Materiais de aula: disponibilização de conteúdos para estudo.
- Categorias: organização dos conteúdos por categorias.
- DevIA: assistente virtual em desenvolvimento para auxiliar os estudantes.

🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Node.js
- Express
- Firebase
- Gemini AI (DevIA)
