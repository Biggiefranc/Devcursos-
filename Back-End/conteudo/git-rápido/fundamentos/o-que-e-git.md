# O que é Controle de Versão?

O **Git** é um sistema de controle de versão distribuído. Ele permite salvar o histórico de alterações do seu código sem precisar criar pastas como `projeto-final-v2`.

## Principais vantagens
* **Histórico completo:** Volte para qualquer versão anterior do código com um comando.
* **Trabalho em equipe:** Várias pessoas editam o mesmo projeto sem sobrescrever arquivos.
* **Segurança:** Se algo quebrar, você descobre exatamente quem alterou e quando.
