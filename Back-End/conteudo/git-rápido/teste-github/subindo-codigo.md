# Git vs GitHub

Enquanto o **Git** roda localmente na sua máquina, o **GitHub** é a plataforma na nuvem onde você hospeda seus repositórios.

## Enviando seu projeto
Após criar um repositório vazio no GitHub, conecte sua pasta local e envie os commits:

```bash
git remote add origin https://github.com
git branch -M main
git push -u origin main
```

Pronto! Seu código agora está salvo na nuvem e pronto para entrar no seu portfólio.
